# 中文运行说明

本包是第 3 周版本，已加入账号功能：每个人注册自己的账号，课程、记录和周报都只属于该账号。解压后即可安装，两个分发包的程序代码一致。首次安装需要联网下载 Python 依赖；安装后，现有功能使用本地数据库运行。

如果这台电脑上还留着第 1、2 周单用户版本的数据库（在 `instance` 目录里），启动时会自动迁移：先在旁边备份一份，旧记录归到一个保留账号，你注册的第一个账号会接管它们。迁移失败会整体回滚，不会留下半新半旧的库。

## 1. 先找到正确的文件夹

请先完整解压 ZIP，不要直接在压缩软件里运行。打开能同时看到 `run.py`、`setup.cmd`、`start.cmd` 和 `planner` 的目录。建议放在 D 盘，例如 `D:\学生生活项目创意\运行副本`。路径含中文可以使用；在 CMD 中必须给完整路径加英文双引号。

电脑需要 Python 3.11 或以上。可以在 CMD 执行 `python --version`，或 `py --version`。如果两条都不能显示正确版本，先安装 Python，再重新打开 CMD。安装时选中将 Python 加入 PATH 的选项。已有的可用 Python 无需重复安装。

## 2. 双击启动

第一次双击 `setup.cmd`，等到依赖安装完成并提示 Ready。安装脚本会把虚拟环境、下载缓存和安装临时文件放在项目目录，避免将这些内容放回原来的 C 盘项目目录。

随后双击 `start.cmd`。看到 `Running on http://127.0.0.1:5000` 后，在浏览器打开该地址。运行期间不要关闭这个黑色窗口；关闭窗口或按 Ctrl+C 后，网站就会停止。以后一般只需要运行 `start.cmd`，更新依赖时再运行 `setup.cmd`。

本包不会附带别人电脑上的虚拟环境，也不会带入个人学习记录，因此新电脑必须先执行安装。两个版本不要同时启动，它们默认都使用 5000 端口。建议每个人选一个目录作为日常开发目录，避免在不同副本中录入数据后找不到记录。

## 3. CMD 方式

在项目文件夹的地址栏输入 `cmd` 并回车，CMD 会直接在正确位置打开。依次输入：

```bat
setup.cmd
start.cmd
```

如果从开始菜单打开 CMD，则先运行以下命令。把示例路径替换成自己的解压目录：

```bat
cd /d "D:\学生生活项目创意\运行副本"
dir
setup.cmd
start.cmd
```

`cd /d` 会同时切换盘符和目录。执行 `dir` 后应能看到 `run.py`。每次只运行一行，等待当前步骤结束后再输入下一行；`start.cmd` 会持续运行服务，不会马上返回命令提示符。

## 4. 登录与导入课表

打开 http://127.0.0.1:5000 后先看到登录页。第一次使用点 **Create account** 注册账号（用户名 3–40 位，密码至少 8 位，两次密码要一致），注册后自动登录；已有账号则直接 Sign in。每个账号只能看到自己的课程、记录和周报。

进入页面的 Import timetable，选择项目目录 `samples` 中的 `timetable-demo.csv`。看到预览以后点击确认，才会写入数据库。空账号应显示 Added 5；重新导入同一文件应显示 Unchanged 5。

首页默认显示**当前这一周**，不再是写死的示例日期。要看样例课表，用页面顶部的日期选择器跳到 2026-09-28 那一周，或在地址后面加 `?week=2026-09-28`。样例周有四节课，第五节在 2026-10-05，点下一周即可看到。

再选择 `timetable-update.csv`，应有一节课变更教室。先取消一次，再重新导入并确认，观察两个结果。`timetable-invalid.csv` 的结束时间不正确，用来验证错误提示，不能当作正常课表使用。`timetable-template.csv` 只有表头，需要填写数据后才能导入。

导入按钮接受的是 CSV，不接受 JPG、PNG、PDF 或 XLSX。目前需要我们参照学校课表整理 CSV，程序随后自动解析并预览。用 Excel 编辑时选择“CSV UTF-8”保存；具体字段及一节课一个 `source_key` 的规则见 [课表格式说明](import-format.md)。同一节课改教室或时间时保留原来的 key，改 key 会被视作另一节课。

## 5. 添加记录和导出 PDF

在周页面填写日期、类型、标题、详情和进度，并为记录选择一个**课程**或一个**研究项目**（可从下拉里选已有的，也可以在输入框里新建一个名字）。课程和研究项目二选一，不能同时选。研究记录选项目、不关联课程也能保存；研究生有课程时仍使用同一个课表导入入口。记录日期决定它出现在哪一周；链接的课程发生变化，不会自动改写记录日期。

在 Make a report 区域填写标题、摘要，勾选需要导出的记录，并决定是否包含课表。下载后检查内容。再次导出会生成新版本，刷新周页面后可查看旧版本。当前尚不支持修改已保存备注的正文或状态，也没有完整任务进度历史；创建时选择的状态只用于本周记录统计。

如果想直接加载演示记录，先停止服务，再在 CMD 运行：

```bat
.venv\Scripts\python.exe scripts\seed_demo.py
start.cmd
```

这个脚本会创建一个演示账号 **`demo` / 密码 `demo-password`**，导入五节示例课和四条记录；仅在没有课程和记录的数据库中添加，已有数据时会跳过并打印 skipped。启动后用 `demo` 登录即可看到数据，也可以自己注册别的账号。先导入课表再运行脚本时看到 skipped 属于正常行为，可以自行添加备注。

## 6. 常见问题

| 现象 | 处理方法 |
| --- | --- |
| `python` 不是内部或外部命令 | 检查 Python 安装和 PATH，重新打开 CMD；也可确认 `py --version` 是否可用 |
| 找不到 `run.py` 或 `setup.cmd` | 当前目录不对，使用 `cd /d`，再用 `dir` 核对 |
| `No module named flask` 或 `reportlab` | 运行 `setup.cmd`，启动时使用 `start.cmd`，避免误用另一套 Python |
| pip 下载失败 | 检查网络或代理，保留具体错误文字，网络恢复后重新安装 |
| 浏览器无法连接 | 确认服务窗口仍打开，并且出现 Running 提示；本机地址不能发给其他电脑直接访问 |
| 5000 端口被占用 | 检查是否已启动另一个副本，先在那个服务窗口按 Ctrl+C |
| 表单过期或预览失效 | 刷新页面，重新选择 CSV 并预览；不要反复提交旧页面 |
| 文件被拒绝 | 读取报错行号；检查 UTF-8、日期格式、时间先后和重复 key |
| 打不开页面，一直跳登录页 | 未登录或登录已过期，注册或登录一个账号即可；每个账号只看到自己的记录 |
| 注册提示用户名已被占用 | 用户名不区分大小写，换一个；或直接用已有账号登录 |
| 登录后看不到之前的记录 | 记录按账号隔离，确认登录的是当初录入数据的那个账号 |
| 启动时提示数据库已迁移 | 正常现象：检测到第 1、2 周的旧库并升级了结构，旁边会生成 `.pre-v3.bak` 备份；注册第一个账号即可接管旧数据 |
| 新副本中没有旧记录 | 数据存于各自的 `instance` 目录，代码压缩包不含个人数据库 |

备份个人数据前先停止服务，再复制整个 `instance` 目录到自己的备份位置。不要把这个目录上传到 GitHub。不要为了运行成功而删除已有学习记录。

## 7. 验证和协作

```bat
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.venv\Scripts\python.exe -m unittest discover -s tests -v
```

现有测试共 33 项，测试使用临时数据库。第 1、2 周的 20 项行为不变，第 3 周新增 13 项，覆盖账号注册登录、跨账号隔离（含直接用他人报告 id 访问应返回未找到）、密码哈希存储、每账号独立的课表修订号、取消状态不被重复导入冲掉、字段级变更历史，以及把第 1、2 周旧库迁移到新结构。`docs/test-results.txt` 是本次检查结果。测试通过后再检查页面操作，尤其是登录、变更课表、取消导入和中英文 PDF。
