# Week 3 | Accounts and ownership of records

We added sign-in and registration and assigned classes, notes and reports to individual accounts. The application checks ownership when retrieving records, including when a student opens a record URL directly.

Courses and research projects now have their own records. Existing users of the single-profile prototype can migrate their data. The migration backs up the old database first. Timetable changes now retain a field-level history, and reimporting a cancelled class preserves its state.

The v1.1.0 milestone passed 33 tests, including account isolation and migration.
