# Week 2 | Importing classes and exporting weekly reports

We implemented the CSV workflow from preview to confirmation. Students can inspect proposed changes and cancel the import. A confirmed batch updates existing classes in place. A stale preview cannot overwrite a newer timetable.

Students can select learning or research records for a weekly PDF and decide whether to include the timetable. Each export stores the selected values and a copy of the PDF, so editing a note later preserves the earlier report.

The first two weeks shipped together as v1.0.0. The 20 checks covered validation, persistence, import transactions, weekly selection and PDF versioning.
